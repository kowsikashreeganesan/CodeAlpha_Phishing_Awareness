# Phishing Awareness Training

## Project Overview
Phishing Awareness Training is a beginner-friendly Python
cybersecurity project designed to educate users about phishing
attacks and common online threats.

The program explains phishing, identifies warning signs in
emails, checks URLs for basic suspicious patterns, and provides
an interactive quiz and online safety tips.

## Features
- Phishing awareness information
- Suspicious email warning signs
- Basic URL warning checker
- Interactive five-question quiz
- Online safety tips
- Menu-driven interface

## Technologies Used
- Python
- Visual Studio Code

## Requirements
- Python 3 installed
- A terminal or command prompt

## How to Run
1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run the command:

   py phishing_training.py

## Testing
The program can be tested using the menu options.
Example URL for testing:

http://example.com/login

The program should identify the HTTP connection and the
suspicious keyword.

## Limitations
This project uses simple rules to identify warning signs.
It does not verify website reputation or guarantee detection
of phishing attacks. A URL without warnings may still be
malicious.

## Learning Outcomes
- Understanding phishing attacks
- Recognizing suspicious URLs and email patterns
- Practicing Python functions, loops, conditions and lists
- Building a menu-driven cybersecurity application
